# ブログ記事 構成テンプレート（保育士の転職）

## 書く前に決めること
- 狙う検索キーワード（1記事に1つ）
- 読者がそのキーワードで知りたいこと（答えを1文で）

## タイトル
- 狙うキーワードを前の方に入れる。32文字前後
- 例：「保育士の転職タイミングはいつ？辞めやすい時期と、半年前から始める準備」

## 構成
1. **導入**：読者の悩みを言葉にする → この記事でわかることを3つ書く
2. **結論**：最初に答えを書く
3. **本文**（見出しごとに1つの疑問に答える）
   - 具体的な手順やスケジュール
   - 数字には出典と時点を書く
4. **よくある不安への答え**（Q&A形式）
5. **まとめ**：次にやることを1つだけ示す

## 公開前チェック
- [ ] 狙うキーワードがタイトルと最初の見出しに入っているか
- [ ] 数字に出典と時点があるか
- [ ] 今の職場や特定の園を悪く言っていないか
- [ ] サービス紹介に「合わない人」も書いたか
- [ ] 広告を含む記事に、広告であることの表記があるか

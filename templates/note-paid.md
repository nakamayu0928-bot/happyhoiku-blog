# 有料note 構成テンプレート

## タイトル
- 型：「（不安を抱えた読者）が（具体的な作業）を（結果）にした方法」
- 例：「AIが怖かった私が、毎月3時間の集計作業を30分にした方法」
- 数字（時間・回数）を入れる。誇大にしない

## 無料パート（全体の3〜4割）
1. **共感**：読者の今の状況と不安をそのまま言葉にする
2. **書き手の立場**：同じ事務員として、自分も不安だった話
3. **安心材料**：この記事は「安全な使い方」から始めると約束する
4. **小さな成功体験**：無料でも1つ使える指示文を渡す（ここで信頼を得る）
5. **有料で得られるもの**：箇条書きで具体的に（例：コピペ用指示文15個、情報漏えいを防ぐチェックリスト）
6. **こんな人向け / 向かない人**

――――― ここから有料 ―――――

## 有料パート
1. 安全に使うためのルール（入れてはいけない情報、置き換え方）
2. 業務別の使い方（1業務＝1章）
   - Before（今の手順と時間）
   - コピペ用の指示文
   - AIの出力例
   - 確認すべきポイント
   - After（短縮できた時間）
3. 職場・上司への説明の仕方
4. つまずいたときのQ&A
5. まとめと次の一歩

## 公開前チェック
- [ ] 専門用語に言い換えがあるか
- [ ] 指示文はそのままコピペで動くか
- [ ] 個人情報の注意に触れているか
- [ ] 誇大表現がないか（brand/voice.md のNG）
- [ ] 無料パートだけでも1つ役に立つか

# ブログ記事の下書き作成

引数：狙う検索キーワードかテーマ（例：「保育士 転職 タイミング」）

## 手順
1. `brand/blog-persona.md`、`brand/voice.md`、`brand/blog-affiliates.md`、`templates/blog-post.md` を読む
2. `blog/published/` に記事があれば2〜3本読み、文体を合わせる
3. テンプレートの表から記事の種類（悩み系・手順系・比較系・個別紹介）を決め、ユーザーに伝える
4. 数字や制度（給与の平均、処遇改善、退職の手続きなど）を書く場合は、公的機関や公式サイトで最新の情報を調べ、出典と時点を書く。調べられなかった数字は書かず、「要確認」と残す
5. 次の順に作る
   - タイトル案5個。おすすめ1つに理由を添える
   - 構成案（見出しのみ）
   - 本文（テンプレートの構成に沿う）
6. テンプレートの「公開前チェック」を自分で確認し、満たしていない項目は直す
7. `blog/drafts/YYYY-MM-DD-スラッグ.md` に保存してコミットする

## 注意
- `brand/blog-affiliates.md` にないサービスは紹介しない。リンクは `{{サービス名のリンク}}` と書いておく
- 体験談は書き手の実体験だけにする。入れたほうがよい場所には `【ここにあなたの体験】` と印をつける
- 最後に、ユーザーに確認してほしい点（要確認の数字、体験談の場所など）を箇条書きで伝える

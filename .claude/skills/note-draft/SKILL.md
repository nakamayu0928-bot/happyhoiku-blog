# note記事の下書き作成

引数：記事のテーマ（例：「メール作成をAIで時短」）

## 手順
1. `brand/persona.md`、`brand/voice.md`、`brand/products.md`、`templates/note-paid.md` を読む
2. `articles/published/` に記事があれば2〜3本読み、文体を合わせる
3. `x/results.md` に実績があれば、反応がよかったテーマや言い回しを参考にする
4. 次の順に作る
   - タイトル案10個（テンプレートの型に沿う）。おすすめ3つに理由を添える
   - 構成案（見出しのみ）
   - 本文（テンプレートの無料パート → 有料ライン → 有料パート）
5. テンプレート末尾の「公開前チェック」を自分で確認し、満たしていない項目は直す
6. `articles/drafts/YYYY-MM-DD-スラッグ.md` に保存してコミットする

## 注意
- コピペ用の指示文は、実際にAIに入れて意味が通る文にする。個人名・社名は「Aさん」「○○社」にする
- 出力例を作るときは、本物らしく見える架空データにする（実在の人・会社を使わない）
- 最後に、ユーザーに確認してほしい点（自分の体験談を入れる場所など）を箇条書きで伝える

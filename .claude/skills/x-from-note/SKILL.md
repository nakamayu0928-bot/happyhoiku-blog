# 記事からX投稿を量産

引数：記事ファイルのパス（`articles/drafts/` または `articles/published/`）

## 手順
1. 記事と `brand/persona.md`、`brand/voice.md` を読む
2. `x/results.md` に実績があれば、伸びた型を多めにする
3. 以下の型で合計12本を作る（告知は全体の2割まで）

| 型 | 本数 | 中身 |
|---|---|---|
| 共感 | 3 | 事務員の「あるある」とAIへの不安を言葉にする。売り込まない |
| ノウハウ | 4 | 記事の無料部分から、1投稿で完結する小技。コピペ用指示文を1つ入れる |
| 不安解消 | 2 | 「情報漏えいが怖い」などに1つずつ答える |
| ツリー | 1 | 5〜7投稿の連投。最後の1本だけ記事リンク |
| 告知 | 2 | 記事で得られることを具体的に。リンク付き |

4. 各投稿は全角140字以内（ツリーは1投稿ごと）。冒頭1行で手が止まるようにする
5. ハッシュタグは0〜1個
6. `x/posts/YYYY-MM.md` に追記する。形式：

```
## 記事：（タイトル）
### 1. [共感]
（本文）
```

7. コミットする

## 注意
- 有料部分の中身そのものは出さない（チラ見せは1つまで）
- 記事URLが `brand/products.md` にない場合は `{{URL}}` と書いておく

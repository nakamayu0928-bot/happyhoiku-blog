# 1週間分のX投稿カレンダー

## 手順
1. `brand/` 以下、`x/results.md`、今月と先月の `x/posts/*.md` を読む
2. 既存の下書きストックで使っていないものを優先し、足りない分を新しく作る
3. 1日2本 × 7日 = 14本。配分の目安：
   - 共感・あるある：4
   - ノウハウ（コピペ指示文つき）：6
   - 不安解消：2
   - 告知：2（`brand/products.md` の優先順位が高い記事）
4. 投稿時間の目安：朝7〜8時（通勤中）、昼12時台（休憩中）。実績があればそれに合わせる
5. `x/posts/YYYY-MM.md` に、次の形式で追記してコミットする

```
## 週：YYYY-MM-DD〜
| 日 | 時間 | 型 | 本文 |
```

## 注意
- 同じ週に同じ指示文やネタを重ねない
- 告知は連続した日にしない

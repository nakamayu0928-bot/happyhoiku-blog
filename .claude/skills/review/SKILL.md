# 実績の振り返り

## 手順
1. `x/results.md` を読む。ユーザーがGoogle Sheetsなどで実績を管理している場合はそちらも読む
2. 次をまとめる
   - 伸びた投稿トップ5と、共通点（型・冒頭の書き方・時間帯・テーマ）
   - 伸びなかった投稿の共通点
   - note購入につながった流れ（どの投稿の後に売れたか）
3. 提案を出す
   - 次に書くべきnote記事のテーマ3つ（読者の不安・悩みとの対応つき）
   - 来週のX投稿で増やす型・減らす型
   - `brand/voice.md` や `templates/` に反映すべき学び
4. データが10件未満のときは、結論を断定せず「傾向の仮説」として出す

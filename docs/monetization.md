# 収益化ロードマップ

> AIを10人に増やしても、**収益を決めるのは「検索で読まれる記事数 × 信頼」**です。
> 記事を大量に作るほど稼げるわけではなく、Google の「大量生成コンテンツ」判定に引っかかると
> サイト全体の順位が落ちます。AI編集部は「1本あたりの質を上げて、運営者の作業時間を減らす」ために使います。

## 収益の柱

| 柱 | 中身 | 向いている記事 | 始める時期 |
|---|---|---|---|
| ① 保育士転職アフィリエイト | 転職エージェント・求人サイトの無料登録で報酬 | キャリア・転職 | 記事10本〜（ASPの審査に通れば） |
| ② Google アドセンス | 記事内広告 | 遊び・製作、保護者向け（PVが多い） | 記事20〜30本・独自ドメイン取得後に申請 |
| ③ 物販アフィリエイト | 製作の材料、知育玩具、絵本、保育グッズ | 遊び・製作、保護者向け | 随時（Amazon・楽天はもしもアフィリエイト経由が楽） |
| ④ 資格講座アフィリエイト | 保育士試験の通信講座 | 保育学生・資格取得 | 記事30本〜 |
| ⑤ 自作デジタル商品 | 指導案テンプレ・おたより文例集・製作型紙 | 全カテゴリから誘導 | 読者が月1万PV超えてから（note / BOOTH） |

報酬単価・広告単価は案件や時期で大きく変わるので、提携時にASP管理画面で必ず確認すること。

## フェーズ

### フェーズ0: 土台（今ここ）
- [x] ブログの仕組み（Astro）・AI編集部10人・PR表記・プライバシーポリシー
- [ ] 運営者情報（`src/pages/about.astro`）に**実際の保育経験**を記入 ← 信頼性の要
- [ ] お問い合わせフォーム（Googleフォーム）
- [ ] 独自ドメイン取得（年1,500円前後〜）。アドセンス審査は独自ドメインが有利
- [ ] 公開（GitHub Pages、`.github/workflows/deploy.yml`）
- [ ] Google Search Console 登録・サイトマップ送信（`/sitemap-index.xml`）

### フェーズ1: 記事10本（1〜2か月）
- 集客記事6本（遊び・製作・保護者向け）+ キャリア記事4本
- ASP登録: A8.net、もしもアフィリエイト、afb など → 保育士転職案件に提携申請
- 提携できたら `src/data/affiliates.ts` の `href` を埋める

### フェーズ2: 記事30本（3〜6か月）
- アドセンス申請（`.env` に `PUBLIC_ADSENSE_CLIENT` / `PUBLIC_ADSENSE_SLOT`）
- `/rewrite` で順位11〜30位の記事をテコ入れ（Search Console で確認）
- SNS自動投稿（`docs/sns-setup.md`）で初期流入を作る。Pinterest は製作記事と相性が良いので手動で

### フェーズ3: 記事50本〜
- 読まれている記事から有料テンプレ・素材集へ誘導
- 収益の高い記事の周辺キーワードを `/monthly-plan` で固める

## 毎週の運営者の作業（目安 2〜3時間）
1. `/new-article` を2〜4回（AIが下書き〜SNS文まで作る）
2. 各記事の `<!-- 体験談 -->` を埋める・「要人間確認」を確認する（ここが他サイトとの差になる）
3. `humanReviewed: true`, `draft: false` にして push → 自動公開
4. SNS: X / Threads / Bluesky は自動。Instagram・Pinterest だけ `drafts/<slug>/08-sns.md` から手動

- AI: お使いの Claude プランの範囲内（1記事あたり10回前後のサブエージェント実行）

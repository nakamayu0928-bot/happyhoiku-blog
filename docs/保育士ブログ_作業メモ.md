# 保育士ブログ 作業メモ

最終更新: 2026-10-07

## ブログの概要
- サイト: https://happyhoiku-tenshoku.com/（WordPress）
- テーマ: 保育士の転職。子育てと仕事を両立したい保育士向け
- 記事の書き方の方針: リポジトリの `content/blog_profile.md`

## 想定読者（ペルソナ）
- 30代の子持ち主婦で、保育士として働いている
- 子どもは4歳と2歳の2人。送り迎えや家事・育児で自分の時間はほとんどない
- サービス残業が続き、心も体も疲れ切っている
- 転職したい気持ちはあるが、勇気が出ない
  - 「今より悪くなったら」「子どもが小さいのに採用されるか」が不安
- 電話は負担。子どもが寝たあとにLINEなどで、自分のペースで相談したい

記事はこの1人に向けて書く。まず「がんばっているあなたは悪くない」と受け止める。そのうえで、情報収集だけ・相談だけなど、小さく始められる行動を示して背中を押す。

## これまでに決めたこと
1. **投稿先**: WordPress（REST API とアプリケーションパスワードで投稿）
2. **記事の作成**: Claude（AI）が自動で執筆する
3. **投稿頻度**: 最初は週2〜3本の予定だったが、**毎日**に変更。毎朝7時（日本時間）に投稿する
   - 投稿は **下書き保存**。自分で確認して「公開」を押す
   - アイキャッチは、Google の画像生成 AI で作る写真風画像にキャッチコピーを重ねる。本文には Pexels の無料写真（実写）を2〜3枚入れる
   - AI 画像が使えないときは Pexels の写真、それもなければイラストのアイキャッチになる
   - WordPress のパスワードは自分で GitHub に登録するので、Claude には伝えない
4. **記事のテーマ**: KW選定スプレッドシートをもとに書く
   - CSVで書き出したものを `content/keywords.csv` に取り込んだ（全42KW、執筆済み2）
   - 執筆済みでないKWを優先度の高い順（最高→高→中）に1つずつ使う
   - 想定検索意図・推奨記事タイプ・備考も記事作成に使う
   - 投稿後は「執筆済み」に日付、「URL」に記事URLを自動で書き込む
   - 未執筆のKWがなくなったら、AIが既存記事と重ならないテーマを選ぶ
5. **記事のルール**
   - 冒頭に「※本記事にはプロモーションが含まれます。」を入れる（ステマ規制への対応）
   - 口コミ・体験談・統計の数字を作らない
   - 紹介サービス（保育エイド、レバウェル保育士）は、方針ファイルに書いた確認済みの事実だけを使う
   - 1記事 3,000〜5,000文字。既存記事への内部リンクを入れる

## しくみ
- GitHub リポジトリ: `nakamayu0928-bot/happyhoiku-blog`（作業ブランチ `claude/hopeful-cerf-ts5bqc`）
- GitHub Actions が毎朝 `scripts/auto_post.py` を実行し、記事の作成から投稿までを行う
- 手動実行: GitHub の Actions →「記事の自動投稿」→ Run workflow
  - 「投稿せずに生成結果だけ確認する」にチェックを入れると、投稿せずに中身だけ確認できる
